    \item Return $\bm{w}^* = \text{argmin}_{\bm{w} \in \{\bm{u}, \bm{v}\}} \|\bm{p} - \bm{w}\|_2$.
\end{enumerate}
Since both sub-routines evaluate exactly 8 scalar roundings and one comparison, the overall complexity is strictly bounded by $O(1)$ memory and CPU steps.
\end{proof}
